# Joshua Mudana · Portfolio

AI/ML engineer. Building Smart Systems.

Live: https://joshuaxcel.github.io/joshuamudana-portfolio/ · also at https://joshuamudana.sites.tab.bot/

Plain HTML/CSS/JS, no build step.

- `index.html`, `styles.css`, `script.js`: the portfolio
- `cv.html`, `cv.css`: printable CV
- `assets/`: fonts and favicon; `og.png`: link preview image

Run locally: `python -m http.server 8000` and open http://localhost:8000. Tests: `node --test`.
